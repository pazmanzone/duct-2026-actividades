# Python - Módulo IV, Actividad Integradora

Autora: María Paz Manzone Rodriguez

El programa lee un texto, cuenta la frecuencia de cada palabra (sin stopwords) y genera un gráfico de barras horizontales con las 10 palabras más frecuentes.

* Código: [analizador.py](src/analizador.py), que se ejecuta desde [main.py](main.py)
* Pruebas: [test_analizador.py](tests/test_analizador.py) y [captura de los tests aprobados](tests/captura_tests_passed.png)
* Texto utilizado: [texto_integradora.txt](data/texto_integradora.txt)
* Salida: [Gráfico de frecuencias](outputs/grafico_frecuencias.png)

## Cómo ejecutarlo

Desde esta carpeta:

```
python -m pip install -r requirements.txt
python main.py
pytest
```
